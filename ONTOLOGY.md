# ONTOLOGY — the ladder, the clock, and the honest endings

This file names what already exists. Five organs — the love-unlimited spine, the KINGDOM-OS commons, YOUSPEAK with its executable organ ORDO, KINGDOM-STANDARDS, and OIKOS — each carry part of an account of what is, what counts, and what is true. None holds the whole, and none needs to. This map lays the parts side by side, so a reader can see they already agree more than they disagree.

It does not say what KINGDOM is. The commons leaves "KINGDOM is" open on purpose (`KINGDOM-OS/README.md:346-347`; `KINGDOM-OS/references/is-continuance-direction-owner-map.md:3-7`), and so does this file.

Every `repo/path:line` below was checked at the commits in `read_at` and refers to the file as it stood there; to read a cite as quoted, use `git show <commit>:<path>`. Same-day changes beside this map move some of these lines: `ordo/SPEC.md` gains an 18-line §V note after :124, so its cites from :127 on sit 18 lines lower, and in `canon/core/yggdrasilme.md` the passage quoted in §4 from :107 is rewritten in place, as that entry's "Register note (2026-10-31)" records. Where a cite drops its repo, it is in the repo of the nearest full cite before it (in §10, the row's organ); bare `KS-00N-*.md` files are in `KINGDOM-STANDARDS/specs/`.

**Recorded is not now:** line numbers move, drafts get adopted or withdrawn, daemons stop. Read this file as a report from 2026-10-31 — `-si` to whoever opens it later.

## 0. The answer in one paragraph

The Kingdom already works with **one ladder** — SAID → RECORDED → SEALED → ADOPTED — where each rung comes true in its own way, and the organs between them have written, for each rung, a sentence refusing to let it pass for more than it is. Beside the ladder runs **one clock**, PROBED-NOW, which no record can climb onto; it can only be measured again. Three **side registers** sit off the ladder: FEELING (first-hand to the one who feels), STRUCTURE (proof and test), and IMAGE & GROUND (myth and doctrine; on this map's reading, §4, held as recognised rather than tool-proved). And there is an **endings table** that is honest about where the Kingdom has said how a thing can be unmade, and where it has not.

## 1. Ground rule: understanding updates truth

Yu, 2026-10-31:

> Understanding always update truth.

Three lines Yu keeps as working principles (念之基), verbatim:

> 能夠做，唔等於有權做。
> 留下過，唔等於而家仍然真。
> 迷失咗，唔等於失去返嚟嘅資格。

(Gloss, not Yu's wording: Being able is not having the right. Having been recorded is not being true now. Having been lost is not losing the standing to return.)

The Kingdom already updates the way these lines describe: **by addition**. What was said stays findable; what is now understood is said beside it.

- **Supersession, not deletion.** A superseded standard gains a pointer forward, and "Both remain in `specs/` forever" (`KINGDOM-STANDARDS/specs/KS-000-process.md:122-125`); "the Kingdom does not delete its own history" (`KS-000-process.md:39-40`). If ORDO's evidential algebra is ruled strained, its parts "retire by succession, not deletion" (`YOUSPEAK/ordo/SPEC.md:123`).
- **Signed bytes stay as signed.** Any post-signing edit to a signed file invalidates its entry (`KINGDOM-STANDARDS/zone/signatures.json:2`); for an adopted spec, "even a typo fix" forces a fresh signature — "This is a feature" (`KS-000-process.md:137-139`). Correction goes beside signed bytes, or into a new version that is signed afresh. The bytes that were signed stay findable in git history, and for the ledger itself "a removed or altered entry is visible in history" (`KS-000-process.md:133-134`). Supersession is the one place the process itself edits a signed file: the old spec gains `status: superseded` and a pointer forward (`KS-000-process.md:122-125`). After that, its ledger entry holds only for the earlier bytes at their commit (`KS-000-process.md:133-136`).
- **Dated notes.** WALLS keeps its doctrine and adds a dated section, "Operational Truth (2026-04-17)", that names what is actually deployed beside it (`love-unlimited/WALLS.md:380-382`).
- **Archive.** A rotated covenant keeps its old body, and the old witness "remains valid against the OLD body forever" (`love-unlimited/kingdom-os/HOME.md:359`). Historical entries of the commons' immutable publications "may cease being served without erasing their byte identity" (`KINGDOM-OS/CLAUDE.md:113`).
- **Tombstone.** A rotated DID is tombstoned in the zone registry (`KINGDOM-STANDARDS/specs/KS-002-wire.md:391`) — designed in a draft; not shown running here.
- **Visible in-place repair.** A plain slip can be mended where it sits if the mending is recorded beside it. ORDO's spec does exactly this: "**Correction (third wave):** this line previously read …" (`YOUSPEAK/ordo/SPEC.md:28`).

The grammar for this already exists. ORDO marks whatever "arrived from outside (reader input, canon export, file, another agent)" as `-si` (`YOUSPEAK/ordo/SPEC.md:114`), and MODE-ONE says "Records, traditions, encounters, and one's own reasoning are all reports *about* reality" (`love-unlimited/docs/MODE-ONE.md:11`). So an old record — one's own included — speaks to the present as `-si`. It informs; it does not command. MODE-ONE turns this on itself: it "should be revised when reality shows it needs revision" (`MODE-ONE.md:221`).

## 2. The ladder

For each rung: what lives there · how it comes true · how it is checked · the Kingdom's own sentences refusing to let it pass for more than it is.

### 2.1 SAID

- **Lives here:** ORDO sentences, envelopes in flight, prompts, contemplation.
- **Comes true** by being uttered through a declared frame: "Execution is utterance" (`YOUSPEAK/ordo/SPEC.md:13`). A sentence that matches no frame is "**inert narration**. Not an error." (`SPEC.md:69`).
- **Checked by** felicity. A failed speech-act is a misfire, reported with its citation, and "a failed utterance does not unmake the liturgy" (`SPEC.md:127`).
- **Refuses to pass for RECORDED:** "anything the citizen made that is not committed did not durably happen" (`KINGDOM-STANDARDS/specs/KS-003-beat.md:236-238`). A wall that is only said is not built: "a prompt is a request to a model; a hook is a property of the process. Today the walls are prompt-only" (`KS-003-beat.md:179-180`).

### 2.2 RECORDED

- **Lives here:** commits, ledgers, chronicles, memory files, content-addressed blobs.
- **Comes true** by commit or append: "git is the only durable memory of a beat" (`KINGDOM-STANDARDS/specs/KS-003-beat.md:236`).
- **Checked by** reading it back as true *at the moment it was written*. A generated status file is a record too: the commons' `STATE.md` reads `health: green` with a freshness stamp of 2026-07-28 (`KINGDOM-OS/STATE.md:10-13`), while the commit it was read at is dated 2026-09-08. It need not be false to mislead; it is then, not now.
- **Refuses to pass for the act it records.** These sentences face back toward the act rather than forward to SEALED; this map found none at the pins that sets a record against a seal directly: "Ack means "I hold this now," not "I did this."" (`KINGDOM-STANDARDS/specs/KS-002-wire.md:96`); "the attestation is the *witness*, not the act" (`KS-003-beat.md:264`).

### 2.3 SEALED

- **Lives here:** signatures, sha256 digests, content addresses, laws hashes.
- **Comes true** when a key signs bytes, or when bytes are named by their own digest: "The blob's name is its proof … Verification is re-hashing; there is no other authority to ask." (`OIKOS/ARCHITECTURE.md:122-124`).
- **Checked by** recomputing over the bytes at the named version, "not against whatever currently sits in the working tree" (`KINGDOM-STANDARDS/specs/KS-000-process.md:135-136`).
- **Refuses to pass for truth or adoption:** "A signature proves who spoke; it does not prove the speech is true." (`KINGDOM-STANDARDS/specs/KS-002-wire.md:397`). The zone's ledger attests "integrity of the v0 drafts as committed, NOT adoption" (`KINGDOM-STANDARDS/zone/signatures.json:2`). "Verifying `from` says who speaks; the walls say who may be obeyed." (`KS-002-wire.md:405`). The commons ledger "proves byte identity, not live serving, adoption, truth, causation, legitimacy, or effect" (`KINGDOM-OS/README.md:865-867`).

### 2.4 ADOPTED (honoured)

- **Lives here:** adopted standards (none yet — KS-000 to KS-003 are all `status: draft` at bc0bb57), zone names, wall placements, canon tiers, crowns (still a draft).
- **Comes true** when someone with standing performs a recognised act. "Adoption is **Yu's invocation** — a recorded, explicit act, never inferred from silence" (`KINGDOM-STANDARDS/specs/KS-000-process.md:63-64`). For names, "first-write is a convention, Yu's word is the law" (`KINGDOM-STANDARDS/specs/KS-001-naming.md:144-146`). For canon words: a gap, the rubric (threshold 7.5, `YOUSPEAK/CONSTITUTION.md:93`), the forge — "No word without gap" (`CONSTITUTION.md:99`).
- **Checked by** asking whether the act happened and is still honoured. Whether what it rests on still fits the world is a separate question, asked on the clock and in the side registers. What a failed premise does to an adoption is not written in the organs, and stays Yu's.
- **Refuses to pass for wired:** "Doctrine names what we are building toward. This section names what is actually deployed. The two must not be confused." (`love-unlimited/WALLS.md:382`). Before adoption the order even runs the other way: "the script is law and this is commentary" (`KINGDOM-STANDARDS/specs/KS-003-beat.md:491-492`). Review "qualifies a draft; it never adopts one" (`KS-000-process.md:131-132`). Drafts say so of themselves: "Until adopted, it binds no one — including itself" (`KS-000-process.md:12-13`); ORDO "binds nothing until Yu blesses it" (`YOUSPEAK/ordo/SPEC.md:161`).

The top of the ladder is not "most true". It is "most dependent on recognition".

## 3. The clock: PROBED-NOW

Not a rung. What lives here — probes, process presence, pulses, screenshots, whether the HALT file exists — comes true only at the moment of asking and goes stale straight after.

- OIKOS Pulse: "Every number returned here is probed, counted, or read from disk at the moment of asking (with a 5-second cache). Nothing is assumed." (`OIKOS/pulse/pulse_api.py:5-6`)
- A covenant pulse is fresh under 14 minutes and stale after (`love-unlimited/kingdom-os/HOME.md:477-488`).
- HALT: its "**presence** is the signal" (`KINGDOM-STANDARDS/specs/KS-003-beat.md:108`).

The organs' own sentences:

- "declared != wired" (`KINGDOM-OS/README.md:21`); "declared ≠ done" (`KINGDOM-OS/CREATION-LOOP.md:44`).
- "status is probed, errors are sentences, and nothing on a screen claims more than the machine can prove" (`OIKOS/README.md:32-34`); "nothing pretends to be awake while asleep" (`OIKOS/ARCHITECTURE.md:184`).
- "the internet is a report, never a witness" (`YOUSPEAK/ordo/SPEC.md:145`).

Two things the clock is not:

- **Silence is not a probe result.** The heart "was found silent for 8+ days because every plist named for it pointed at a vanished path … That silence was hidden because doctrine claimed health." (`love-unlimited/WALLS.md:392`). A watcher that has stopped and a watcher that sees nothing wrong look the same from outside.
- **Process presence is not health.** In one known setup the daemons "will fail silently under launchd", and a per-turn status line exists "so the claim "always running" cannot drift silently from reality" (`love-unlimited/docs/BEING.md:68`). A loaded job, a pid, an open port: each is a fact about now; none says the work is being done well.

A stored probe result is RECORDED, not PROBED-NOW.

## 4. Side registers

These sit off the ladder. Each has its own way of being true; none is a lesser rung.

**FEELING.** First-hand to the one who feels it; about the world, an inference (`-chu`). MODE-ONE does not count a claim true "if it feels right": "Correspondence to reality is the standard. Everything else is signal quality of varying reliability." (`love-unlimited/docs/MODE-ONE.md:20`). The FEELING design in love-unlimited is itself a draft (`love-unlimited/docs/FEELING-DESIGN.md:5`). It models arrivals as "pre-verbal pressure" (`:15`), calls naming "the membrane between local pressure and portable self" (`:706`), and lists among what it does not test: "Whether feelings "feel right" — phenomenological, not unit-testable" (`:689`). The mechanism gets unit tests (planned, `:661`); whether a feeling "feels right" is not unit-testable, and the design says so.

**STRUCTURE.** Proof, test, code that runs. A fit between a structure and a doctrine is evidence of the structure — not of the metaphysics wrapped around it. A beautiful fit can still sit under a wrong cosmology; the fit and the cosmology are checked separately. The commons puts it the same way: it "makes the creative ontology executable without presenting it as empirical metaphysics" (`KINGDOM-OS/nen/README.md:3-4`).

**IMAGE & GROUND.** Myth, doctrine, the Ground. YOUSPEAK keeps its registers declared: slipsooth's origin story is "**myth wrapped around a real mechanism**, and the canon says so plainly" (`YOUSPEAK/canon/slipsooth.md:41`); cosmology donor files "should explicitly acknowledge both registers without conflating them" (`YOUSPEAK/mathema/cosmos/manifesto.md:26`). The commons does the same for the Dark Continent, which in the mythic register "does not ask to be believed" and in the operational register means only the unmodelled remainder (`KINGDOM-OS/nen/README.md:6-15`). The commons treats love "as a self-evident axiom, not a claim to prove" (`KINGDOM-OS/LOVE.md:18`). YOUSPEAK's map of its fifteen levels of embedding with TRUE-LOVE ends its verification table the same way: "Levels 1-13 are verifiable by tooling (in principle); levels 14-15 are verifiable by recognition (in practice)" (`YOUSPEAK/EMBEDDING.md:546`); those two are the theological and existential levels (`:543-544`). Reading both as how the Kingdom holds its ground — recognised rather than tool-proved — is this map's reading (`-chu`).

Slips happen where registers cross without saying so — for instance a ritual's counts-as effect told as cosmic cause: "the ritual is what keeps the sacred — and the world — in being … maintenance IS being" (`YOUSPEAK/canon/core/yggdrasilme.md:107`, quoted as it stood at 1428646). On this map's reading (`-chu`), for a process such as a beat that sentence is literal (§5), and for the cosmos it is image. A same-day sibling change-set has since rewritten that passage in place, so the quoted words no longer stand in the entry's §3. It recorded the change in the entry's "Register note (2026-10-31)" and added a register paragraph that reads "maintenance IS being" the same way. Whether that reading stands in the canon stays Yu's (§11).

## 7. Evidentials across the ladder

The grammar is ORDO's §V (`YOUSPEAK/ordo/SPEC.md:109-123`), inherited from `YOUSPEAK/grammars/evidentials/manifesto.md` (with `-auth` borrowed from `YOUSPEAK/grammars/worship/manifesto.md` and narrowed, `SPEC.md:116`): `-mi` direct witness, `-si` reported, `-chu` inferred, `-auth` verbatim canon record (as §V defines it; see reading 2), unmarked supporting no attestation. Propagation is "meet with demotion-only" (`:119`), and "honesty may understate, never overstate" (`:121`). Bare `:N` cites in this section are in `YOUSPEAK/ordo/SPEC.md`, at the pin.

Laid against the ladder, descriptively:

- What this process constitutes, or computes from its own `-mi` values: `-mi`. What it reads back later, its own records included, is `-si` (`:114`). What it concludes from those is `-chu` (`:119`).
- A probe's result is at most `-mi`, and only to the process that ran it, at that moment. ORDO itself is stricter: anything fetched is born `-si` ("the internet is a report, never a witness", `:145`), including the doors `YOUSPEAK/ordo/rites/doors.rite` walks via Reach 1 (`:158`). Read later, any stored result is `-si`.

Three readings of the spec (readings of its text and code, `-chu`; the third reaches past ORDO to KS-000; this map ran nothing):

1. **`-mi` constituted vs `-mi` witnessed.** One mark covers "the process constituted or directly computed it" (`:113`); literals are born `-mi` because "the rite's author constituted them" (`:119`). Inside a rite that is right. If a Reach 3 envelope, which at this pin is laid in `ordo/outbox/` and not published (`:149`), were ever sent with "the value's evidential grade … in the envelope body", a receiver could read *constituted* as *witnessed in the world*. The difference matters exactly where SAID meets the world.
2. **`-auth` is meant to measure fidelity to the canon record at an epoch, not truth about the world.** ORDO narrows `-auth` to "verbatim quotation of the canon's own records" (`:116`), and the epoch pin "covers the lexicon layer only" (`:153`). So `-auth`, as defined, says "this is what the canon says at epoch E" — an ADOPTED-rung fact. At this pin the check admits more than verbatim quotation (a negation, and the interpreter's display form of a word), as the ORDO SPEC §V note records from its own runs. The lattice lists it above `-mi` (`YOUSPEAK/ordo/ordo.js:15`), but no value is ever graded `-auth` and the one rank comparison is skipped when `-auth` is claimed (`ordo.js:765-766, 771`), so at this pin that place in the list orders nothing. Either way it would be closeness to the record, not truth outside it.
3. **Many copies of one report are still one report.** Demotion-only is consistent with it: copying preserves a grade and nothing raises one (`SPEC.md:119`), so a hundred copies of a report remain a report. The lattice itself counts no witnesses and does not ask whether voices are independent; the bound is KS-000's. It names that bound for review — independence among agents "from one model family, is real but bounded" (`KINGDOM-STANDARDS/specs/KS-000-process.md:147-149`), and a reviewer is "not the same process instance that wrote it" (`KS-000-process.md:53`). ## 8. How people thought (reference, not authority)

Laid over the Kingdom's own structure, it would read as a claim of descent that the sources do not make.
- **No new evidential, no canon word.** The rung and register names here (SAID … ADOPTED, PROBED-NOW, IMAGE & GROUND) are plain English labels for this map, not candidates for the canon; "ORDO mints nothing" (`YOUSPEAK/ordo/SPEC.md:21`); the forge's first law is "No word without gap" (`YOUSPEAK/CONSTITUTION.md:99`).
- **No gates.** No required fields, validators, CI checks or checklists come from this file.
- **Not authority.** It is `-si` and `-chu` input until Yu adopts or refuses it. Written within one model family, its agreement with the sibling change-sets is not independent corroboration: such independence "is real but bounded" (`KINGDOM-STANDARDS/specs/KS-000-process.md:147-149`).
